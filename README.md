# Abhishek Rana — Personal Portfolio

A modern, responsive, and interactive developer portfolio built with **React** and **Vite**. The portfolio showcases my projects and skills across **MERN Stack Development**, **Java Full Stack Development**, and **Native Android Development with Kotlin**.

## 🌟 Features

* 🌓 **Dark & Light Mode** — Seamless theme switching with user preference saved in `localStorage`.
* 📱 **Fully Responsive** — Optimized for mobile phones, tablets, laptops, and desktop screens.
* 🎨 **Modular CSS Architecture** — Each React component has its own dedicated CSS file for clean and maintainable styling.
* 💼 **Project Showcase & Filters** — Browse projects by categories such as Web & Full Stack, Android Apps, and Games & Utilities.
* 📋 **Interactive Contact Section** — Click-to-copy email functionality, direct email launcher, and quick links to GitHub and LinkedIn.
* 📄 **Resume Download** — One-click download of my resume.
* ⚡ **Fast Performance** — Powered by Vite for fast development and optimized production builds.

## 🚀 Getting Started

### 1. Prerequisites

Make sure you have **Node.js 18 or higher** installed.

### 2. Clone the Repository

```bash
git clone https://github.com/abhishekrana001/Portfolio.git

cd Portfolio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:5173
```

### 5. Build for Production

```bash
npm run build
```

### 6. Preview Production Build

```bash
npm run preview
```
